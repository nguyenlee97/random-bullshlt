NP-6 Placement Recommendation Experiment

Deterministic baseline vs dense + BM25 vs dense + BM25 + GPT-5.4-nano

Decision

Selected setup: Dense semantic + BM25 + GPT-5.4-nano topic reranking. It reached 100% top-1 and top-3 accuracy across all 43 cases, including direct topic, semantic-synonym, and audience-only cases. The cost is latency: p95 12.6s versus 0.077s for the baseline. Deterministic performance, creative compatibility, and availability checks remain final guards.

Test design

Production build observed before the experiment: 2026-07-27.1. Catalog: 258 placements across 25 topic documents. The labeled suite contains 23 direct topic cases, 10 paraphrased semantic cases, and 10 audience-only cases. Every configuration received the same catalog and campaign inputs.

Baseline: catalog keyword/context score + performance Hybrid: text-embedding-3-small + in-process BM25 + RRF Nano: bounded topic reorder; known IDs only
