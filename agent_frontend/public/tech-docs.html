01Trạng thái hiện tại

Ứng dụng đã vượt qua mức hackathon prototype ở nền tảng kiến trúc, nhưng chưa phải release production hoàn chỉnh. Campaign Copilot, workspace phiên bản hóa, RAG audience, creative intelligence và Autopilot foundation đều chạy được; các tích hợp provider dài, browser E2E và chất lượng golden set vẫn cần tiếp tục gia cố.

ĐÃ CÓ Nền tảng

Docker Compose, health/readiness, API key proxy, rate limit, structured logs, metrics, Langfuse, canonical workspace và optimistic revision.

ĐÃ CÓ Agent

Campaign Copilot, LangGraph freeform, proposal/approval, dependency invalidation, durable Autopilot tasks, pause/resume/retry/replan và final launch gate.

ĐÃ CÓ Intelligence

Hybrid audience RAG, query rewrite, critic selector, deterministic exclusion guard, VLM creative analysis, zone ranking và order guard.

ĐANG GIA CỐ Release

Golden-label human review, real upload/provider journeys, browser E2E và full performance-report loop. Multi-format AI generation đã code-complete, đang chờ sign-off journey thật.

02Hai chế độ làm việc

Campaign Copilot

Người dùng cùng AI điều khiển Brief → Audience → Creative → Setup → Result. Chat giải thích hoặc tạo proposal; thay đổi chỉ vào canonical workspace sau khi được duyệt.

Campaign Autopilot

Người dùng đưa brief, chọn nguồn creative và chính sách duyệt. Worker chạy capability graph, ghi artifact có revision/evidence và dừng tại review hoặc launch gate.

Ranh giới quan trọng: Mode được chọn một lần trên trang chủ và cố định cho campaign. Trong Autopilot, chat bị khóa khi worker đang chạy, chỉ nhận quyết định duyệt/từ chối tại review gate, rồi chuyển thành hỏi đáp chỉ đọc sau khi run kết thúc. Tạo order luôn yêu cầu launch approval; VLM cảnh báo hoặc độ tin cậy thấp luôn chuyển sang người dùng.

04Workspace và luồng phi tuyến

Mỗi artifact có value, status và revision. Một thay đổi được tạo thành proposal với base revision; khi duyệt, server commit atomically, tăng workspace revision và chỉ đánh dấu stale các artifact phụ thuộc.

flowchart LR B[Brief] --> S[Strategy] S --> A[Audience] --> T[Targeting] T --> I[Placement intent] I --> FP[Creative format plan] FP --> C[Upload / generate creative] C --> V[Creative verdict] I --> P[Final compatible placements] V --> P --> AS[Assignments] --> F[Forecast] --> D[Order draft] --> G[Order guard] --> H{Launch approval} --> O[Create + verify order] --> R[Report]

Ví dụ: đổi budget làm strategy/forecast/order draft stale nhưng không xóa file creative. Thay creative chỉ yêu cầu phân tích, placement compatibility và assignments chạy lại. Kết quả worker chậm bị từ chối nếu input revision đã đổi.

05300+ audience datapoint được chọn thế nào khi không có reranker?

Không bật reranker không có nghĩa là chọn ngẫu nhiên. Pipeline hiện tại vẫn có hai lớp retrieval, hợp nhất thứ hạng, lọc an toàn và một selector bị khóa vào candidate IDs.

Giữ nguyên tín hiệu trong briefBrand, objective, KPI, notes và các câu loại trừ được bảo toàn.
Query rewrite theo nhiều khía cạnhTạo các truy vấn bổ sung nhưng kiểm tra coverage để không làm mất ý định gốc.
Hybrid retrieval trong QdrantDense multilingual MiniLM tìm ý nghĩa; sparse BM25 giữ từ khóa/chính tả; Reciprocal Rank Fusion hợp nhất hai danh sách.
Merge đa truy vấnDeduplicate theo segment ID, ưu tiên best rank và dùng mức đồng thuận giữa query làm tie-break.
Candidate pool hữu hạnChỉ top 25 catalog-backed candidates đi tiếp. Nếu reranker tắt hoặc lỗi, thứ tự hybrid được giữ nguyên.
Exclusion guard + critic selectorTaxonomy guard loại xung đột rõ ràng; GPT critic chọn đúng 6 trong whitelist. ID ngoài candidate pool bị từ chối.
Kết quả regression gần nhất: recall@15 0,819 · MRR 0,851 · p95 5,51 giây · 0 audience-exclusion violation trên run hậu sửa. Đây là kết quả eval, không phải cam kết chất lượng cho mọi brief.

06Creative: tải lên hoặc để AI tự tạo

Trước khi bắt đầu Autopilot, người dùng phải chọn rõ một nguồn:

Upload

Nếu chưa có file, task dừng với hành động retry. Sau khi user upload, run dùng lại canonical file và đi qua deterministic analysis + VLM.

AI generate

Worker chọn tối đa ba format exact-size từ placement intent, tạo song song có giới hạn, lưu idempotently, rồi đưa tất cả asset qua cùng luồng creative analysis.

flowchart LR PI[Placement intent] --> FP[Deduplicate exact formats
cost cap = 3] FP --> CH{Creative source} CH -->|upload| WAIT[Wait for canonical files] CH -->|ai_generate| GEN[Bounded multi-format generation] GEN --> FIT[Exact-size normalization] FIT --> STORE[Revision-idempotent storage] WAIT --> DET[Deterministic checks] STORE --> DET DET --> VLM[VLM semantic + safety analysis] VLM -->|high confidence, safe| NEXT[Final exact-size placement] VLM -->|warning / timeout / low confidence| REVIEW[Human review]
Phạm vi hiện tại: Hỗ trợ các family có trong zone catalog: 300×250, 300×600, 1160×250, 1160×280, 2032×528 và skin. Zone cùng kích thước dùng chung một asset; format không hỗ trợ được báo rõ. Mỗi format hiện tạo một variant.

07An toàn, độ bền và observability

Structured outputs

MiniMax dùng function calling vì spike đạt schema-valid 10/10; model output vẫn được Pydantic validate.

Durable worker

Run/task ở Mongo, bounded retry, worker lease + heartbeat, pause/resume/cancel và idempotency boundary.

Side-effect gate

Order guard chạy server-side. Launch approval luôn là human gate; edit sau create không replay side effect.

Evidence

Mỗi task ghi catalog IDs, selector/rerank state, analysis IDs, order guard result, trace ID và artifact revisions.

Prometheus cung cấp request/LLM/tool/order metrics; Grafana hiển thị dashboard; Langfuse nhận traces khi cấu hình. Trace ID ổn định theo một Autopilot run, còn request ID có thể đổi ở mỗi HTTP request—đó là hành vi bình thường.

Test Campaign Copilot nhanh

  1. Tải mới trang và xác nhận luôn thấy trang chủ, hai mode và lịch sử campaign.
  2. Chọn Campaign Copilot, nhập brief tiếng Việt, yêu cầu chat sửa budget và kiểm tra proposal chưa tự ghi.
  3. Duyệt proposal; mở Audience và kiểm tra segment có ID/catalog source.
  4. Sửa lại brief sau khi đã có audience; kiểm tra banner stale/recompute thay vì reset mọi thứ.
  5. Về trang chủ, mở lại campaign trong lịch sử và xác nhận mode cùng workspace được khôi phục đúng.

Test Autopilot upload

  1. Chọn Autopilot trên trang chủ, tạo và duyệt brief.
  2. Chọn “Tôi sẽ tải creative lên”, chọn policy, bắt đầu.
  3. Xác nhận chat bị khóa khi run đang chạy và chỉ nhận duyệt/từ chối khi có review gate.
  4. Xác nhận run dừng ở “Chuẩn bị creative” nếu chưa có file.
  5. Upload file, bấm retry; xác nhận VLM result hoặc manual-review card.

Test Autopilot AI generate

  1. Chọn “Để AI tự tạo creative”, sau đó bắt đầu.
  2. Theo dõi task “Chuẩn bị creative”: file phải xuất hiện trong canonical workspace với source=ai_generated và generation provenance.
  3. Kiểm tra Audience hiển thị tên segment/lý do chọn; Forecast hiển thị budget, CPM catalog, frequency, reach cap và công thức.
  4. Nếu VLM an toàn, run đi tiếp; nếu timeout/rủi ro, run phải dừng review.
  5. Dù policy là auto-build, run vẫn phải dừng ở launch approval trước create order.
  6. Sau duyệt launch, order phải ở trạng thái active. Báo cáo hiệu suất phải ghi rõ số liệu tổng hợp là synthetic để minh họa, không giả làm delivery thực.
Không dùng nút review để “ép qua” lỗi provider. Retry chỉ hợp lệ khi input hoặc external state đã được sửa. VLM timeout chuyển manual review là fail-safe, không phải bằng chứng creative đã đạt.

Bộ test hiện định nghĩa 128 unique scenarios. Đây là test specification và report contract, không phải tuyên bố cả 128 case đã chạy/passed. Input/expected output cho AI tester nằm trong docs/testing/COMPREHENSIVE-TEST-PLAN.md, SCENARIO-CATALOG.md và AI-TEST-EXECUTOR-PROMPT.md.
